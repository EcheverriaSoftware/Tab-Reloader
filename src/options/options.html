Tab Reloader

Settings & defaults

Default interval

New tabs use this interval unless you set a per-tab override. This value persists across browser sessions and may sync across your devices.

Allowed range: 1–1440 minutes (24 hours). Values outside are clamped.

Auto-reload rules

Say “this site, always” once and stop re-adding the same tabs by hand. Any tab whose URL matches an enabled rule joins the reload list on its own — when it opens, when it navigates there, and at browser start for tabs that are already open. Rules persist across sessions and follow your Chrome profile; the reload list itself does not.

    No rules yet. Open a site you always want kept alive and click “Always reload this site” in the toolbar popup, or add one below.

    A pattern is a host with an optional *. subdomain wildcard and an optional path prefix — portal.example.com, *.example.com, example.com/admin/*. No regex; scheme, port, and query string take no part in matching. Leave the interval blank to use the default above. When several rules match one tab, the most specific one sets the interval.

    Disabling or deleting a rule stops future enrollment. Tabs it already enrolled keep reloading until you remove them.

      How it works

      • The list of reloading tabs is per session — it clears when the browser closes. Auto-reload rules persist, and rebuild the list each morning.
      • Taking a tab off the list sticks for the session: a rule won't immediately re-add what you just dismissed. Opening the site in a new tab enrolls it again.
      • A refresh is skipped silently while you're viewing that tab (it's the active tab in the focused window).
      • Manually reloading a tab resets its timer to a full interval.
      • Events persist across sessions. An event that was due while the browser was closed does not fire late — recurring events re-arm for next time; missed one-time events are listed above.
